# London Gameday Navigator

Offline-fähige iPhone-Web-App (PWA) für den London-Trip zu Eagles @ Jaguars, 11.–12.10.2026.

Installieren: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“ → einmal mit Internet starten.

## Umgezogene Apps
Trip Assistant und Schedule haben jetzt eigene Repos:
- Trip Assistant: https://github.com/trolloberg/trip-assistant → https://trolloberg.github.io/trip-assistant/
- Schedule: https://github.com/trolloberg/schedule → https://trolloberg.github.io/schedule/

Die alten Kopien unter `travel/` und `stundenplan/` laufen weiter, bis alle Daten per Backup umgezogen sind, und werden hier nicht mehr aktualisiert.
